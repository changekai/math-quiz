# 🔢 九九乘法表懲罰遊戲

> 答錯了？做伏地挺身！一個讓你快速背熟九九乘法表的互動小遊戲。

## 🎮 Live Demo

👉 [立即挑戰](https://math-quiz-chi.vercel.app)

## ✨ 特色功能

- 🎯 **兩種模式**：選擇題 / 填寫答案
- 💀 **懲罰系統**：伏地挺身、深蹲、跳繩、喝水、自訂
- ⏱️ **倒數計時**：可自訂答題時限（預設 10 秒）
- ❤️ **生命制**：答錯扣血，考驗你的正確率
- 🔥 **連勝加分**：連續答對獲得額外分數
- 📊 **結果報告**：完整懲罰清單，讓你知道欠多少下
- 📱 **響應式設計**：手機平板都能玩
- ⚡ **零依賴**：純 HTML/CSS/JS，不需安裝任何東西

## 🕹️ 玩法說明

1. **設定遊戲**：選擇模式、懲罰類型、每題懲罰次數、乘數範圍等
2. **開始挑戰**：在時間內回答乘法題目
3. **答錯懲罰**：畫面顯示懲罰提示，記錄待執行項目
4. **結果統計**：遊戲結束後查看完整報告與懲罰清單

## ⚙️ 可設定項目

| 設定 | 說明 | 預設值 |
|------|------|--------|
| 遊戲模式 | 選擇題 / 填寫答案 | 選擇題 |
| 懲罰類型 | 伏地挺身 / 深蹲 / 跳繩 / 喝水 / 自訂 | 伏地挺身 |
| 每題懲罰 | 答錯一題要做幾下 | 5 下 |
| 乘數範圍 | 幾到幾的乘法表 | 2 到 9 |
| 答題時限 | 每題幾秒 | 10 秒 |
| 題目數量 | 共幾題 | 20 題 |
| 生命數 | 可答錯幾次 | 3 條 |
